# 部署位置和字节

公开 Qwen 候选在训练前生成并缓存；本机未重跑生成，T_generate 未测。客户端 MiniLM 对自身 staged 记录编码并形成整数投票，随后本地加离散几何噪声和选 ID；云端按公开 ID 恢复 64 条文本做 BP/GGD，下游 FedFwd 客户端仍用真实记录。此次仅在同一 A6000 主机上共址运行，非 Jetson 或实际客户端网络测量。

冻结候选池 JSONL 文件为 33918 B；若完整发送给两个未缓存客户端，文件内容共 67836 B。对已有 D01 发布采用明确 JSON ID 参考编码，两个客户端 ID 负载共 3043 B、独立头部共 114 B；已有完整文本发布文件为 17814 B。这些是文件或参考序列化器的真实字节计数，**不是**现有 MPI 的线上流量；缓存命中后候选下行可为 0。原训练梯度消息含完整参数张量，仅按 float32 内容推导每次 267,252,880 B，不含 pickle/MPI 头、模型下发或 GGD。

MiniLM 加载 1.298 s，编码投票 7.158 s，公开零直方图 20 次噪声加选样的中位时间 0.0044 s；样本 GPU 显存峰值 10628 MiB（5 s 采样）。T_serialize、真实链路、能耗未测。一次性准备成本须与每轮云 BP/GGD 和 FedFwd 临界路径分列，不把并行客户端时间相加。
