# 实验与写作共用约定

版本：2026-10-14。两份Codex任务必须遵循同一约定，避免互相造成方法与证据漂移。

## 1. 不变的研究问题

客户端继续用本地真实数据训练任务模型。新增机制替代云端BP/GGD的数据来源，不替换整个联邦训练集。原贡献：ZGR＋SPC/DTC；新增一个完整的隐私合成指导供给/分析贡献。

不声称首次想到synthetic data；KDD已经提及可能来源。复用生成器、DP定理和既有研究须明确归属。

## 2. 方法版本与状态

当前用于最小闭环的是已有公开Qwen候选池＋私有投票top-r，不在本轮改成小生成器、聚类或概率采样。Qwen是冻结实验的来源，不是最终最佳模型结论，也不默认在端侧运行。

DP参考实例：固定名册/公开池/配额，replace-one完整记录，一记录一票，整直方图一次Laplace噪声，逐类top-r为后处理。实际投票不满足条件时停止该DP实例，不能论文写top-r而代码运行另一机制。

- `proposed`：协议设想，不能写已实现。
- `implemented`：有代码，不代表正确性或隐私已审查。
- `audited`：规定的实现检查完成，数学命题与实现前提逐项映射；仍明确数值假设。
- `evaluated`：真实任务已完成且工件校验。
- `confirmed`：新候选/客户端或冻结确认协议的证据；不能把固定池3seeds自动升级到此状态。

数学机制满足DP是条件性命题。实际实现的审计状态另外记录，不用实验成功替代证明。

## 3. 统一实验编号

- E0：正确性、协议与旧结果复用。
- E1：PUB_RANDOM / PUB_NLI / PRIVATE_ZERO / REAL_MATCHED，固定池4臂×3seeds。
- E2：PRIVATE_DP_E4，3独立发布工件与FL seeds配对。
- E3：共同checkpoint指导诊断与初步组件成本。
- E4+：后续投稿隐私/Q/泛化/规模/受控系统测试，仅计划。

本轮目标15个完整终点，不自动执行E4+。官方测试集本轮不读。

## 4. 精度和重复的口径

`updates_completed=0`是训练前；50是第50次更新后，对应历史round49。主指标accuracy百分数，差值使用百分点。

`guidance_slots=64`与`unique_texts`独立报告。128指导的旧v3只能单独列，不和当前64预算直接作因果差。

固定候选池与固定源客户端，FL种子变化只覆盖训练随机性。DP三次试验混合DP随机化与训练随机性；需另做设计才能分解。

真实指导是参考，不是已证明的性能上界。公开类别同意率不是下游准确率。波动不显著不等于统计等效。

## 5. 隐私范围与公开材料

仅合成指导发布通道。保护记录，不保护整个客户端；完整FL更新和scalar loss未保护。即使cloud复用DP数据，来自未保护FL的模型状态也阻止把整个training transcript简单称为DP后处理。

同一DP工件复用和重新独立加噪发布区别记账。E2若3次ε4独立工件全公开，针对同一客户端数据的基本组合上界为12。Non-DP参考不是ε0；与目标记录完全独立的公开方案仅就该发布通道可记零隐私访问。

论文/公开Git不携带私有文本、原始票数、逐记录匹配、可还原噪声的seed、认证材料。开发集和下游模型指标本身不因为发布机制DP而自动包含在其保护范围。

## 6. 证据优先级与冲突

当前用户确认的研究范围优先。关于已发生事实：可核验的实际工件/源码/manifest → 同协议新汇总 → 20261014研究报告 → 更旧报告。

出现冲突不默默选择有利值：写明冲突、保留原记录、标为待核验；错误修正需指明影响哪些结果。

待完成/准备好的任务不能升级为已完成。旧论文数字不能填新DP表格。没有现场成本测量不填推算数字冒充实测。

## 7. 交接和并行

写作端只修改IEEE_ToN及其notes/build；实验端只修改实验仓库/结果与paper_handoff，不自动触碰论文。

两个会话可并行，但使用分离目录或worktree，避免同时修改同一个文件。不要自动git push。

实验端导出：PAPER_EVIDENCE_MANIFEST、PROTOCOL_FOR_PAPER、RESULTS_FOR_PAPER、TABLES_FOR_PAPER、THEORY_IMPLEMENTATION_MAP。

写作端收到后核验status/协议/budget/出处，再填新增表和结果段，仍全部标红。未经核验的内容只能当计划或明确标出的初步观察。
